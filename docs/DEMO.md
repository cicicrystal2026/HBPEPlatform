# V3 省体育局领导演示手册

业务日期固定2027年8月9日，以康保草原马拉松为主线。所有身份、商户、支付、消息及资格审核为模拟。

## 准备

运行npm start，电脑打开/#screen，两台手机同一可信局域网打开电脑IP的/#mobile、/#merchant。大屏1920×1080或3840×2160、浏览器100%；手机逻辑尺寸393×852。点击重置恢复开场。商户端可开启到账语音，需浏览器中文语音支持与用户点击；文字到账不受影响。

## 扩展闭环

- 首赛：会员中心抵扣→扣3,000积分、实付30元、段位+50；模拟现场检录后转化指标+1、段位另+100。重复抵扣与检录被拦截。
- 资质：我的选手账号→段位→申请指导员；后台积分与会员→模拟主管部门审核，生成Demo证书编号。
- 券码：我的权益券购198元双人券；商户券码核销填最新待用券、确认，券面价不可编辑。购买不计核销消费，使用后才计入。
- 套餐：旅居计划参赛套餐→预置实名授权→模拟支付1,280→住宿凭证；商户入住填最新凭证、确认。住宿680元、分成20.40入账，报名费单列。
- 退款：我的→买单与权益记录→模拟退款，消费、分成与会员积分冲减，保留退款记录，账单重新待确认。
- 询价：企业团建套餐→询价，至少10人；后台显示记录，不发送真实询价。
- 账单：下钻支付流水→办赛方确认→省局确认→选择服务费冲减或扶持资金池。下载CSV；报告打印另存PDF。

## 口径

赛事人数合计366,300按各赛事去重相加；运营档案366,373（74,120选手+292,253观众）为PRD独立样本，两组不可替代。转换后保留观赛历史，两种身份可重叠。初次报名不等于转化，首次检录才计入。

套餐开场651单/份=236参赛+412亲友+3团体单，覆盖700人=236+412+52；团体占比52/700=7.4%。名额已售288=236+52。比赛日已过名额释放日，名额池展示历史销售口径，新购买为回放模拟。

银卡正式规则含倍率，Demo脚本指定核销固定+200，采用脚本规则并留快照。数据增长开关只模拟观众入场、独立标记，不生成真实身份。默认关闭，重置即暂停。

所有资源本地保存，无需外网；断外网可电脑localhost单机操作，后端须运行。不接真实扫码、身份、和包、短信、报名或和美乡途接口。可选入口为直播制播、积分商城与粉丝互动说明。

## 券码与住宿凭证衔接修正

商户核销页没有待用订单时直接引导去购券或购买套餐；已支付订单自动填入完整凭证，支持选择待核销订单。观众端已购券、住宿订单可一键带码切到商户端，也可复制后在另一手机粘贴。未领票用户先领票，随后自动返回购券。258元买单支付成功即核销，不需再走198元券码入口。4位手机验证码不是住宿凭证。错误信息在表单内显示，核销后有成功回执；全部完成时显示已核销/已入住状态，重置可重新演示。
