# 省体育局汇报演示手册

## 演示前

启动 `npm start`，电脑接大屏，两台手机连接同一局域网。屏幕推荐1920×1080或3840×2160，浏览器缩放100%。点击全屏演示，再重置数据。观众端和商户端可在同一浏览器的不同标签页打开；也可使用两台独立手机。

演示业务日期固定为2027年8月9日，操作时间为当前设备时间；每页标注演示环境。请勿输入真实证件、手机号或商户账户。

## 20分钟讲解

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0–3分钟 | 数据舱全省总览 | 11场重点赛事归集。上报376008、测算391328，总量差约3.9%，单场误差仍显著。 |
| 3–5分钟 | 点击邢台轮滑 | 测算39509、上报2500、实名37900；用口径对照定位数据问题。 |
| 5–8分钟 | 后台数据接入 | 三渠道6150条，重复150条，去重6000人；聚合现有报名系统。 |
| 8–12分钟 | 手机观众端领取票根 | 观众游客进入实名链路；预置演示身份验证后签发，每人每场一张。 |
| 12–15分钟 | 手机商户端核销258元 | 草原人家餐厅满200减30；输入票根编号，每项权益单独计次。 |
| 15–17分钟 | 返回数据舱 | 核销1260→1261，消费315000→315258，滚动条显示现场新增记录。 |
| 17–20分钟 | 后台结算中心 | 商户分成9450→9457.74，归集59135→59142.74；核销可追溯，办赛方/省局依次确认，展示收益去向。 |

## 设计与交互

大屏以真实河北市级轮廓为中心，用深蓝背景和青绿色强调实名与消费，琥珀色标识需关注的偏差；左侧赛历与分布，右侧口径对照与消费，底部核销信息。

运营端使用浅色管理工作台，突出数据源、去重过程和账单可追溯性。手机端采用草原绿与米白色，原生 CSS 草原插画，避免依赖外部素材。393×852原型对应iPhone15逻辑尺寸。

## 范围说明

这是可运行的高保真产品 Demo，不是生产交付。相机扫码用票根号路径替代；验证采用虚拟身份；动态码图案仅展示。结算确认模拟角色，不冒充生产权限。报告支持浏览器另存PDF；账单下载CSV。各地市均可下钻，无数据的地市展示空状态。手机在可信局域网访问同一服务实现多端同步。

可选项“直播制播、运动员数字档案”为后续扩展说明，不影响本次主线。自动增长未启用，避免现场新增记录与自动造数混淆。所有数字变化均可追溯到演示操作。
