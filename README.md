# 冀动 · 河北省体育赛事数智服务平台 V3 Demo

基于用户提供的2026-10-09 V3 PRD第十五、十六部分Demo范围与模拟数据，为省体育局领导25分钟汇报设计的四端可交互产品。主线为2027康保草原马拉松，所有支付、实名、审核、订单均为模拟。

## 启动

Node.js 20或以上，无需npm install，无第三方运行依赖。

```sh
npm start
```

打开 `http://localhost:3000/#screen`。监听0.0.0.0:3000；两台手机与电脑连接同一可信局域网，打开 `http://电脑IP:3000/#mobile` 和 `/#merchant`，四端须访问同一服务实例。

| 入口 | 页面 |
| --- | --- |
| /#screen | 全省总览、赛事日、邢台、地市、观众转化率、套餐与团体客源、模拟增长开关 |
| /#admin | 工作台、赛事详情、报名归集、档案与票根、商户、结算、积分会员与资质审核、旅居套餐及和美乡途订单、用户运营漏斗与任务、报告、审计 |
| /#mobile | 领票、动态票根、权益地图、票根买单与支付结果、权益券、记录、会员、首次报名抵扣、段位、观众/选手身份切换、旅居套餐与企业询价 |
| /#merchant | 实时到账、到账语音开关、权益券码核销、酒店入住核销、经营数据 |

## 体验闭环

1. 大屏三口径对照，点邢台看偏差；后台三渠道6,150条归集、150条重复合并。
2. 观众免费领票，模拟验证、授权，不输入真实资料。
3. 票根买单258元→优惠30元→锁定订单→模拟支付228元；自动到账、核销、积分入账。
4. 大屏消费+258，分成+7.74，会员积分3,260→3,460。支付回调幂等，退款冲减原记录。
5. 消耗3,000会员积分抵首次报名30元，实付30元；完成检录后才计入观众→选手转化，段位分独立入账。
6. 切换选手看Lv.4、年度2,360、累计4,180及指导员申请；后台模拟主管部门审核。
7. 套餐购买→报名与票根凭证→酒店入住→住宿分成入账；后台和美乡途团体订单与企业询价同步展示。
8. 运营看板执行任务，账单下钻支付流水、两级确认、选择收益去向；重置恢复全部设备。

## 技术与范围

原生HTML/CSS/JavaScript、Node.js HTTP、SSE共享状态，断线自动重连；`.data/state.json`持久化，PORT与DATA_DIR可指定端口和目录。V3业务集中于v3-business.js、public/v3-ui.js、public/v3-data.js。无外部字体、CDN或图片依赖。

大屏支持1920×1080、3840×2160；移动端为393×852的iPhone15 H5原型，非原生微信小程序。河北市级轮廓来源：[阿里云DataV](https://geo.datav.aliyun.com/areas_v3/bound/130000_full.json)，本地缓存作可视化示意。

金额以整数分汇总，分成逐笔3%取两位小数；赞助50,000元、通道费315元为固定样例。新核销与退款重新打开账单确认。套餐住宿履约680元进入消费、报名费单列。订单数、覆盖人数、团体人数分别统计。

积分账户不互转；PRD银卡倍率与Demo固定+200有差异，采用现场脚本并保存规则快照。资质编号显式标记Demo，不产生真实证书。动态码60秒刷新，码图仅作视觉展示，券码/入住凭证走手输备用路径。

不采集真实个人信息，不接相机、短信、支付、和美乡途、报名平台或真实资质接口。报告打印另存PDF，账单下载CSV。无外网仍可localhost单机演示；后端停机不能写入。仅用于可信演示网络，不作生产公开部署。仓库不含原始PRD、凭据或运行状态。
