# 冀动 · 河北省体育赛事数智服务平台 Demo

为省体育局汇报设计的四端可交互原型，基于 2026-10-02 PRD 第十二、十三部分。以 2027 康保草原马拉松为主线，所有业务均为模拟，不接入生产系统。

## 启动

安装 Node.js 20 或以上，无需 npm install，无外部运行依赖。

```sh
npm start
```

打开 http://localhost:3000 。默认监听 0.0.0.0:3000；两台手机与电脑连接同一可信局域网，手机使用 `http://电脑局域网IP:3000/#mobile` 和 `/#merchant`。必须访问同一服务实例才能跨设备同步。无需公网、CDN、数据库或外部字体。

| 入口 | 页面 |
| --- | --- |
| `/#screen` | 领导数据舱：全省、赛事、地市下钻 |
| `/#admin` | 工作台、赛事详情四页签、三渠道接入、实名档案、票根、商户、账单、报告、审计 |
| `/#mobile` | 观众/参赛者：赛事首页、模拟实名、票根夹、动态码展示、权益地图与记录 |
| `/#merchant` | 商户：票根号核销、成功回执、今日经营 |

## 完整演示闭环

1. 大屏查看全省三口径对照，点击邢台轮滑或康保马拉松进入赛事。
2. 后台“数据接入”：最酷 3100、赛会通 1800、汇跑 1250，合并重复 150，得 6000 名参赛者。
3. 观众端领取观赛票根，点击“模拟验证”，勾选演示授权并领取。不输入真实个人信息。
4. 复制票根编号。在第二台设备的商户端粘贴，或使用“填入最新演示票根”。输入消费 258 元，确认核销。
5. 大屏和后台实时增加一笔核销、258 元消费、7.74 元商户分成。观众端“我的”显示节省 30 元。
6. 后台结算中心查看明细，模拟办赛方确认、省局确认，选择收益去向。可导出 CSV，报告可打印另存 PDF。
7. 右上角“重置”恢复开场状态。该操作同步清空全部设备的现场演示记录。

内置“演示导览”提供 20 分钟讲解顺序。详见 [演示手册](docs/DEMO.md)。

## 技术结构

- 原生 HTML/CSS/JavaScript 前端、Node.js HTTP 服务；零第三方运行依赖。
- SSE 推送共享状态；断线自动重连，重连获取完整快照。
- `.data/state.json` 保存模拟状态，服务重启后恢复。`DATA_DIR` / `PORT` 可覆盖目录和端口。
- 服务端校验票根存在、满减门槛、金额精度与每人每权益限用一次；重复提交不会重复计入。
- 账单：核销消费 × 3% + 50,000 元赞助 − 315 元固定示例通道费；新增消费使账单重新进入确认流程。
- 桌面移动原型画布 393×852（iPhone 15 CSS 逻辑尺寸），真实手机响应式展示；大屏适配 1920×1080 与 3840×2160。
- 河北市级地图使用本地 GeoJSON，来源：`https://geo.datav.aliyun.com/areas_v3/bound/130000_full.json`。仅作数据可视化示意，非测绘用途。

## 数据口径与范围

PRD 中的测算、上报数字原样保留。全省实名指标为赛事内去重人数之和，跨赛事可能重复，不宣称全省自然人去重。消费、票根、核销与商户数据标明康保试点。趋势和画像为示意，不作为真实分析结论。

动态码每60秒更新；码图为演示图案，使用 PRD 允许的“输入票根号”备用路径完成实际闭环。未实现相机扫码、短信、真实身份校验、支付、真实第三方接口、生产权限隔离。商户为虚构，地图为位置示意，不跳转真实导航。无网时保持电脑本地服务和局域网即可演示；不支持后端停机后的离线写入。

仅适合可信演示网络，**不得作为含个人信息的生产系统直接公开部署**。仓库不包含原始 PRD、凭据或运行数据。
